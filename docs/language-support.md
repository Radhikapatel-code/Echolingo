# Language Support Matrix

This document provides the complete language compatibility matrix for Echolingo's 65 supported languages.

## Overview

Echolingo supports exactly 65 languages end-to-end through the following pipeline:
- **STT**: OpenAI Whisper (base model)
- **Translation**: Google Translate (via deep-translator)
- **TTS**: Google Text-to-Speech (gTTS)

## Provider Support Details

### OpenAI Whisper (STT)
- **Model**: base (~150MB)
- **Languages**: 99 languages (includes all 65 Echolingo languages)
- **Source**: https://github.com/openai/whisper/blob/main/whisper/tokenizer.py

### Google Translate (Translation)
- **API**: Google Translate via deep-translator
- **Languages**: 100+ languages (includes all 65 Echolingo languages)
- **Source**: https://cloud.google.com/translate/docs/languages

### Google Text-to-Speech (TTS)
- **API**: gTTS
- **Languages**: 65 languages (exactly matches Echolingo support)
- **Source**: https://gtts.readthedocs.io/en/latest/module.html#languages

## Notes

1. **Language Code Normalization**: Some language codes are normalized for deep-translator compatibility (e.g., "zh-CN" for Chinese Simplified)

2. **Hebrew Code**: Uses "iw" (legacy ISO code) instead of "he" for gTTS compatibility

3. **Chinese Variants**: Both Simplified (zh-CN) and Traditional (zh-TW) are supported as separate languages

4. **TTS Quality**: gTTS produces functional but robotic speech. For production use, consider upgrading to Coqui XTTS or ElevenLabs

5. **Translation Accuracy**: Google Translate quality varies by language pair and content complexity
